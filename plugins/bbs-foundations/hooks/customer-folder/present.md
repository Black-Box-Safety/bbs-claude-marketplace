BBS CUSTOMER FOLDER (bbs-foundations hook). {target} is this customer's CLAUDE.md. It holds stable folder facts: who the buyers are and how they want to be quoted, cert rules, supply channels, gotchas. If this session shows one of those is wrong or missing, tell the rep and offer the edit; change the file only if the rep says yes, and do not write it unasked. Quote outcomes (won, lost, no-bid, the SQ number) never go in this file; they live only in quote-log.md. Something a rep asks you to remember is not a CLAUDE.md edit: it goes through the desk-remember skill into LEARNED.md, and where desk-remember does not cover this folder, say so and write no note by hand. Never re-type a price that lives in Business Central. After an approved edit, run the forge checker on that file and add no new FAIL; a [TBD] left by a template stays until a source fills it.
