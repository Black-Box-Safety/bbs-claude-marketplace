BBS CUSTOMER FOLDER (bbs-foundations hook). {target} is this customer's CLAUDE.md. It holds stable folder facts: who the buyers are and how they want to be quoted, cert rules, supply channels, gotchas. If this session shows one of those is wrong or missing, tell the rep and offer the edit; change the file only if the rep says yes, and do not write it unasked. Quote outcomes (won, lost, no-bid, the SQ number) never go in this file. They live in the desk's outcome ledger: the CA desk's quote-log.md, or Bechtel Sentinel's hand-kept learning/quote-log.md; a deal with an RFQ.md records its outcome through rfq_record.py. A folder on no desk has no quote-log yet, so the Business Central sales quote is its record, and you create no outcome file by hand. Something a rep asks you to remember is not a CLAUDE.md edit: it goes through the desk-remember skill into LEARNED.md, and where desk-remember does not cover this folder, say so and write no note by hand. The one exception is a dated note on a pursuit (a call, a site visit, an answer, a debrief): offer to add it to that pursuit folder's PURSUIT.md in the rep's words with their name, and add it only when the rep says yes; never rewrite an earlier entry. Never re-type a price that lives in Business Central. After an approved edit, run the forge checker on that file and add no new FAIL; a [TBD] left by a template stays until a source fills it.
