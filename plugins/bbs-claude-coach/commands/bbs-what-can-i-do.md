# /bbs-what-can-i-do

Run the `bbs-claude-coach` skill in **capability-map** mode.

1. Read `references/jobs-map.md` and `references/glossary.md` from this plugin's
   `bbs-claude-coach` skill.
2. Ask once what kind of work they have open (or infer from the conversation if they
   already said).
3. Present a short map: job → first step → which plugin area. Keep it scannable.
4. Remind them everyone can use the whole toolkit — no desk walls.
5. Offer one next command if useful (`/bbs-start`, `/bbs-explain-claude`, `/bbs-checkup`,
   `/bbs-my-voice`, or the sales commands when an RFQ is clearly in play).
6. Do not start a quote, form fill, or CLAUDE.md rewrite from this command — route.
