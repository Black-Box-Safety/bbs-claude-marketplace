# bbs-marketing

Layer 0. This plugin is the factory for Black Box Safety marketing pieces. The SharePoint
folder `MARKETING/bbs-marketing/` is the desk: program folders, logo files, and finished pieces.

Read `CONTEXT.md` next and open only the skill it names. Then open only the reference files
that skill lists. Do not load the whole `references/` tree to answer one question.

## Where a fact lives

| Fact | File |
|---|---|
| Approved wording | `references/CLAIMS.md` |
| What a piece may say | `references/COMPLIANCE.md` |
| Which expression | `references/tracks/ROUTING.md`, then exactly one track file |
| Voice | `references/VOICE.md` |
| Argument | `references/MESSAGING.md` |
| Buyer | `references/AUDIENCES.md` |
| Logo permission | `references/ASSETS.md` |
| Where a statement came from | `references/SOURCES.md` |

A fact that is not in `references/CLAIMS.md` is `NEEDS CLAIM: <description>` in the draft.
Do not edit the registry to make a piece pass. Do not re-type a claim into a skill.

California pieces use the California wording in the registry. Federal and prime pieces use
`bbs-deck-voice` in `bbs-foundations`. One piece carries one channel.

## What this plugin does not do

It does not send email, place orders, write Business Central, or file a quote under
`Customers/State of CA Agencies/`. CSU, UC, and body-armor marketing stay in this plugin.
They stay out of the Kim/Aanya quote book. A priced Grainger hot-list page is
`grainger-promo-page` in `bbs-sales`.

A human sends. Tier B needs `approved-by:` with a person's name and a date in the program
README before anything renders.
